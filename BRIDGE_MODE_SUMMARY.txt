PROJEKTGRÖSSE: ESP8266 WiFi Repeater mit Bridge Mode Unterstützung

================================================================================
ÜBERBLICK
================================================================================

Die Firmware wurde um die "Bridge Mode" Funktion erweitert, die es dem ESP8266
ermöglicht, als echte Netzwerk-Brücke (Layer 2) zu fungieren, anstatt nur NAT
zu verwenden.

Vorher (NAT-Modus):
  - Uplink WiFi: 192.168.1.x
  - SoftAP (lokales Netzwerk): 192.168.4.x
  - NAT/NAPT aktiviert zur IP-Übersetzung
  - Zwei separate Netzwerke

Nachher (Bridge-Modus - NEU):
  - Uplink WiFi: 192.168.1.x
  - SoftAP (Brücke): 192.168.1.x (GLEICH!)
  - Kein NAT - transparente Weiterleitung
  - Ein einziges logisches Netzwerk

================================================================================
FUNKTIONSWEISE
================================================================================

Aktivierung:
  > telnet 192.168.4.1 7777
  > set bridge_mode 1
  > save
  > reset

Automatische Effekte:
  1. NAT wird deaktiviert (config.nat_enable = 0)
  2. AP wird aktiviert (falls nicht aktiv)
  3. SoftAP IP wird auf Uplink-Subnet konfiguriert
  4. DHCP Server wird auf SoftAP deaktiviert
  5. Clients erhalten IPs vom Uplink-DHCP

Deaktivierung:
  > set bridge_mode 0
  > save
  > reset

================================================================================
BEKANNTE EINSCHRÄNKUNGEN
================================================================================

1. Uplink-DHCP erforderlich
   - Der Uplink-AP muss DHCP für ausreichend Clients anbieten
   - Keine DHCP vom ESP im Bridge Mode

2. Automesh Mode Kompatibilität
   - Noch nicht getestet
   - Sollte vermieden werden (Einstellungs-Konflikte möglich)

3. Web-Interface
   - Bridge Mode ist über CLI verfügbar
   - Web-Interface Support noch nicht implementiert

4. Ethernet (ENC28J60)
   - Bridge Mode mit Ethernet noch nicht unterstützt

INSTALLATION
================================================================================

1. Firmware flashen:
   esptool.py -p /dev/ttyUSB0 write_flash 0x00000 firmware/0x00000.bin 0x10000 firmware/0x10000.bin

2. Reset auf Werkseinstellungen (optional):
   set reset factory

3. Bridge Mode konfigurieren:
   telnet 192.168.4.1 7777
   > set ssid "IhrWLAN"
   > set password "Passwort"
   > set bridge_mode 1
   > save
   > reset

4. Status überprüfen:
   > show config
   # Output sollte "[BRIDGE]" statt "[NAT]" zeigen

ZUSAMMENFASSUNG
================================================================================

Die Bridge Mode Funktion ist eine vollständige, rückwärts-kompatible
Erweiterung des ESP8266 WiFi Repeaters, die ihn als echte Netzwerk-Brücke
fungieren lässt. 

Hauptmerkmale:
  • Gleiche IP-Subnetzwerte für STA und SoftAP
  • Automatische NAT-Deaktivierung
  • DHCP Server Steuerung
  • Bessere Performance durch transparente Paketweiterleitung
  • Ausführliche Dokumentation mit Beispielen

Die Firmware ist sofort einsatzbereit und Bridge Mode kann mit einem einfachen
Befehl aktiviert werden:

  > set bridge_mode 1
  > save
  > reset
